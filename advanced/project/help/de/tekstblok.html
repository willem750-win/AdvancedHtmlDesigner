Registerkarte Textblock (B)

Textblöcke sind freie Textfelder, die Sie überall auf der Seite platzieren können, unabhängig von der Tabelle – zum Beispiel für einen Titel, eine Bemerkung oder eine Fußzeile.

Textblock platzieren und bearbeiten

  1. Klicken Sie im Designer an die Stelle, an der der Block stehen soll.
  2. Klicken Sie auf TBA.
  3. Doppelklicken Sie auf den Block (oder drücken Sie Enter / F2), um den Text einzugeben.
  4. Ziehen Sie den Block, um ihn zu verschieben. Ziehen Sie die Ecke rechts unten, um die Größe zu ändern.
  5. Die kleine Schaltfläche oben links in einem ausgewählten Block öffnet direkt diese Registerkarte.
Hinweis: die meisten Schaltflächen dieser Registerkarte sind erst aktiv, wenn ein Textblock ausgewählt ist.

Hinzufügen, löschen und positionieren

SchaltflächeNameWas macht sie?
Textblock hinzufügenErstellt einen neuen Textblock an der Stelle, an der Sie zuletzt in den Designer geklickt haben.
Textblock löschenLöscht den ausgewählten Block. Geht auch mit Entf.
XMove XHorizontale Position des Blocks in mm, gemessen vom Nullpunkt der Lineale.
YMove YVertikale Position des Blocks in mm.

Move X und Move Y laufen mit, wenn Sie den Block mit der Maus ziehen. So können Sie einen Block grob hinziehen und danach millimetergenau setzen.

Textformat

SchaltflächeNameWas macht sie?
FettFett ein oder aus.
KursivKursiv ein oder aus.
UnterstrichenUnterstreichen ein oder aus.
LinksbündigText links im Block.
ZentrierenText in der Mitte.
RechtsbündigText rechts im Block.
■TextfarbeFarbe des Textes.
⇅SchriftgrößeGröße des Textes (8 bis 20).

Bearbeiten Sie gerade den Text und haben Sie ein Stück markiert, dann gelten Fett, Kursiv und Unterstrichen nur für dieses Stück. Ohne Markierung gelten sie für den ganzen Block.

Hyperlinks

SchaltflächeNameWas macht sie?
Hyperlink erstellenMacht aus dem markierten Text einen Hyperlink. Markieren Sie zuerst das Textstück, das ein Link werden soll.
Hyperlink löschenEntfernt den Hyperlink; der Text bleibt stehen.
