Dateien & Export

Ihren Entwurf speichern und öffnen, und den HTML-Code verwenden.

Entwurf speichern und öffnen (.htd)

SchaltflächeWas macht sie?
Tabellendesigner speichernSpeichert den vollständigen Entwurf (Tabelle, Formatierung, Bilder, Textblöcke und Seite) als .htd-Datei. Standardmäßig im Ordner htd neben dem Programm.
Tabellendesigner öffnenÖffnet eine früher gespeicherte .htd-Datei.

Beim Start wird automatisch die letzte Arbeitsdatei htd\temp.htd geladen.

HTML-Code anzeigen und exportieren

Klicken Sie unten auf Hier klicken für Extrafunktionen, um den Bereich auszuklappen. Sie sehen dann zwei Registerkarten:

RegisterkarteInhalt
Html-DokumentDie vollständige HTML-Seite, fertig zum Speichern als Datei oder für eine Website.
Html-TabelleNur der Code der Tabelle, zum Einfügen in eine bestehende Seite.

Auf beiden Registerkarten können Sie:

  • In die Zwischenablage kopieren – den Code kopieren, um ihn woanders einzufügen.
  • HTML-Dokument speichern – den Code als .html-Datei speichern.

Die Registerkarte Html-Dokument hat außerdem Test-Browser öffnen: damit sehen Sie das Ergebnis in Ihrem normalen Webbrowser. Der Bereich klappt danach wieder zu.

Bilder: das HTML verweist auf den Ordner images. Wenn Sie die Seite an einen anderen Ort verschieben, nehmen Sie diesen Ordner mit.

Sprachdatei

Die Übersetzungen stehen in talen.lng neben dem Programm. Bearbeiten Sie sie über Sprache... auf der Registerkarte Einstellungen.
