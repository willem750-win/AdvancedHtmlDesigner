Settings tab (S)

Default values for new documents, the page size and the language of the toolbox.

Managing default settings

ButtonNameWhat does it do?
Load default settingsReads the saved default settings again.
Save default settingsSaves the current values on this tab as the default.
Factory defaultsRestores all values to the original factory settings.
Apply to documentApplies the default values to the document that is currently open.
Note: changing a value on this tab does not yet change your current table. Click Apply to use them on the current document, or Save to remember them for later.

Default values

SettingMeaning
Default column widthWidth of new columns.
Default row heightHeight of new rows.
Default grid line widthThickness of the lines between the cells.
Default grid colourColour of those lines.
HTML background colourBackground colour of the page (the body of the HTML document).
Show layout gridShows a dotted grid on the page to help with positioning.
Show page rulersShows the rulers in mm above and to the left of the page.
Show headersShows the row and column headers (1, 2, 3… and A, B, C…) around the table.

Page size

The page size button opens a menu: A3, A4, A5 or Letter, each in portrait or landscape. The button shows the chosen size; the width and height in pixels are shown next to it.

Language

ButtonNameWhat does it do?
Display languageFlag button: click to choose Dutch, English, French or German from a menu. The button shows the flag of the current language; the toolbox hints and the window texts switch immediately.
Edit translationsOpens the language editor. There you adjust the translations and save them in talen.lng.
Language editor: the first column (Key) is the lookup key from the source code and cannot be changed. Only edit the NL, EN, FR and DU columns.
