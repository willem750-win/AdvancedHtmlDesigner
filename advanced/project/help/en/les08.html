Learning path › Lesson 8

From design to website

Goal: save your design as a real web page (.html), understand the HTML code and open a saved page again later to carry on working.

▶ Open this example

Design or web page?

FileWhat is it?Open with
.htdYour design, to keep working on.Advanced Html Designer
.htmlThe web page, as visitors see it.any web browser (and the designer too)

Viewing the HTML code

Click Click here for extra functions at the bottom. The roll-out panel has two tabs:

  • Html Document: the complete web page, with the text blocks and the page settings.
  • Html Table: only the table, to paste into an existing web page.

The most important parts of the code:

CodeMeaning
<table>start of the table (</table> is the end)
<tr>a row (table row)
<td>a cell (table data); colspan and rowspan for merged cells
style="..."the formatting: colours, borders, alignment, font size
<a href="...">a hyperlink
<img src="...">an image; the image itself is built into the code (data:image/png...)
<div class="designer-textblock">a text block
Note: the code is made at the moment you open the roll-out panel. Did you change something in the designer after that? Then close the roll-out panel and open it again.

Turning it into a web page

  1. Open the example (or your own design) and open the roll-out panel.
  2. On the Html Document tab click Save HTML document.
  3. Choose a folder and a name, for example fruitshop.html.
  4. Double-click the file in Explorer: it opens in your web browser. Click the links to test them.

Because the images are built into the code, your web page is a single file. You can e-mail it, put it on a USB stick or place it on a website. Many web hosts require the home page to be called index.html.

Opening a web page again

An .html file saved with Save HTML document also contains your complete design, invisibly. Open it with Open table designer and you can simply carry on working, even without the .htd file. More about this in Files & export.

Exercise

Save the example as fruitshop.html and open it in your browser. Bananas are getting cheaper: they now cost €1.75 per kg. Change the price in the designer, save the web page again and refresh your browser (F5). Then find the address of the link behind Bananas in the HTML code.

Solution

Close the roll-out panel, double-click the price of the bananas in the designer and type the new price. Open the roll-out panel again, click Save HTML document and choose the same file: the old one is replaced. Press F5 in the browser and you see the new price. In the code the link reads <a href="https://en.wikipedia.org/wiki/Banana">Bananas</a>.

Well done! You have completed the whole learning path. Now make your own web page: about your hobby, your class, your sports club or your holiday. Use everything you have learned.
