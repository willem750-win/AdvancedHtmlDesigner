Cell tab (C)

Formatting of the selected cell(s): text, colours, hyperlinks and images.

Selecting: click a cell, drag over several cells, or click a row or column header to select a whole row or column. The formatting applies to the whole selection.

Text formatting

ButtonNameWhat does it do?
BoldTurns bold on or off.
ItalicTurns italic on or off.
UnderlineTurns underline on or off.
Align leftAligns the text to the left.
CentreCentres the text.
Align rightAligns the text to the right.
⇅Font sizeSize of the text in the cell.
■Text colourColour of the text.
■Cell colourBackground colour of the cell.
─Cell border styleStyle of the border around the cell.

Copy and paste

ButtonNameWhat does it do?
Copy cellCopies the content and formatting of the selected cell(s). Shortcut Ctrl+C.
Paste cellPastes what was copied into the selected cell. Shortcut Ctrl+V.

Text hyperlinks

ButtonNameWhat does it do?
Create text hyperlinkTurns the selected text into a hyperlink. You enter a URL and optionally a text.
Delete text hyperlinkRemoves the hyperlink; the text stays.

How to: double-click the cell, select the piece of text that should become a link and click TH+.

Images

ButtonNameWhat does it do?
Add imageChooses an image for the cell. The file is copied to the images folder, so the HTML can refer to it later.
Delete imageRemoves the image from the cell.
Image leftPlaces the image on the left of the cell.
Image centrePlaces the image in the middle.
Image rightPlaces the image on the right.
Image sizeOpens a menu to choose the size of the image.
Create image hyperlinkTurns the image into a clickable link.
Delete image hyperlinkRemoves the link from the image.
