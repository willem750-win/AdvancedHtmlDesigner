Bestanden & export

Je ontwerp bewaren en openen, en de HTML-code gebruiken.

Ontwerp bewaren en openen (.htd)

KnopWat doet het?
Opslaan tabel designerBewaart het volledige ontwerp (tabel, opmaak, afbeeldingen, tekstblokken en pagina) als .htd-bestand. Standaard in de map htd naast het programma.
Openen tabel designerOpent een eerder bewaard .htd-bestand, of een .html-bestand dat je met Bewaar HTML Document bewaard hebt (zie HTML opnieuw openen).

Bij het opstarten wordt automatisch het laatste werkbestand htd\temp.htd geladen.

HTML-code bekijken en exporteren

Klik onderaan op Klik hier voor extra functies om het rolluik uit te klappen. Je ziet dan twee tabbladen:

TabbladInhoud
Html-DocumentDe volledige HTML-pagina, klaar om als bestand te bewaren of in een website te zetten.
Html-TabelAlleen de code van de tabel, om in een bestaande pagina te plakken.

Op beide tabbladen kun je:

  • Kopiëren naar klembord – de code kopiëren om ergens anders te plakken.
  • Bewaar HTML Document – de code als .html-bestand opslaan.

Op het tabblad Html-Document staat bovendien Open test-browser: daarmee bekijk je het resultaat in je gewone webbrowser. Het rolluik klapt daarna weer dicht.

Met PDF (Bewaar als PDF) op het tabblad Html-Document bewaar je de pagina als PDF-bestand, op het papierformaat van de pagina en met alle kleuren, afbeeldingen en tekstblokken. Zie ook les 8 van het leerpad.

HTML opnieuw openen

Een HTML-document dat je met Bewaar HTML Document bewaart, bevat onzichtbaar ook je volledige ontwerp, met de afbeeldingen. Je kunt zo'n .html-bestand later met Openen tabel designer opnieuw openen en verder bewerken, ook als je het .htd-bestand niet meer hebt.

  • In de browser zie je hier niets van: het ontwerp staat in een blok dat de browser niet toont.
  • Open je het bestand op een andere pc, dan worden de afbeeldingen uitgepakt in een map naast het HTML-bestand (bv. pagina_images).
  • Gewone HTML-bestanden (van een website of uit een ander programma) kunnen niet geopend worden; je krijgt dan een melding.
  • Met grote afbeeldingen wordt het HTML-bestand groter, omdat de afbeeldingen mee in het ontwerp zitten.
Afbeeldingen: de afbeeldingen zitten in de HTML-code ingebouwd (data:image/...). Je webpagina is dus één bestand: je hoeft geen aparte map met afbeeldingen mee te nemen.

Taalbestand

De vertalingen staan in talen.lng naast het programma. Bewerk ze via Taal... op het tabblad Instellingen.
