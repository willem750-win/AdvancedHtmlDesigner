Fichiers & export

Enregistrer et ouvrir votre conception, et utiliser le code HTML.

Enregistrer et ouvrir une conception (.htd)

BoutonQue fait-il ?
Enregistrer le concepteur de tableauEnregistre toute la conception (tableau, mise en forme, images, blocs de texte et page) dans un fichier .htd. Par défaut dans le dossier htd à côté du programme.
Ouvrir le concepteur de tableauOuvre un fichier .htd enregistré auparavant.

Au démarrage, le dernier fichier de travail htd\temp.htd est chargé automatiquement.

Voir et exporter le code HTML

Cliquez en bas sur Cliquez ici pour des fonctions supplémentaires pour déplier le volet. Deux onglets apparaissent :

OngletContenu
Document HtmlLa page HTML complète, prête à être enregistrée comme fichier ou mise sur un site web.
Tableau HtmlUniquement le code du tableau, à coller dans une page existante.

Dans les deux onglets, vous pouvez :

  • Copier dans le presse-papiers – copier le code pour le coller ailleurs.
  • Enregistrer le document HTML – enregistrer le code dans un fichier .html.

L'onglet Document Html contient en plus Ouvrir le navigateur de test : il affiche le résultat dans votre navigateur habituel. Le volet se referme ensuite.

Images : le HTML fait référence au dossier images. Si vous déplacez la page ailleurs, emportez aussi ce dossier.

Fichier de langue

Les traductions se trouvent dans talen.lng à côté du programme. Modifiez-les via Langue... dans l'onglet Paramètres.
