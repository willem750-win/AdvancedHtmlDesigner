Bienvenue

Advanced Html Designer vous permet de concevoir visuellement un tableau HTML sur une page, avec des cellules mises en forme, des images, des hyperliens et des blocs de texte librement placés. Vous enregistrez le résultat comme conception (.htd) ou comme code HTML.

La fenêtre

  • Concepteur – la grande zone de travail avec la page, les règles (en mm) et le tableau.
  • Boîte à outils – la barre de boutons flottante à gauche. En haut, choisissez T, C, B ou S pour afficher l'onglet voulu.
  • Boutons en haut – ouvrir et enregistrer une conception, aide, à propos et fermer.
  • Volet déroulant en bas – cliquez sur Cliquez ici pour des fonctions supplémentaires pour voir le code HTML et un aperçu du résultat.
Astuce : laissez la souris un instant immobile sur un bouton de la boîte à outils : une courte explication (info-bulle) apparaît dans la langue choisie.

La boîte à outils change souvent d'onglet toute seule : cliquez sur une cellule et l'onglet Cellule apparaît. Le petit bouton en haut à gauche des en-têtes du tableau ouvre Tableau, et le petit bouton d'un bloc de texte sélectionné ouvre Bloc de texte.

Windows et Linux

Advanced Html Designer existe en version Windows et en version Linux.

  • Windows – décompressez le zip et lancez Advanced Html Designer.exe. Aucune installation n’est nécessaire.
  • Linux (Debian, Ubuntu, Linux Mint…) – installez le paquet .deb avec sudo apt install ./advanced-html-designer_<version>_amd64.deb. Le programme apparaît ensuite dans le menu sous Développement. Pour le supprimer : sudo apt remove advanced-html-designer.
  • Linux avec Wine – la version Windows fonctionne aussi sous Wine : wine "Advanced Html Designer.exe".
Linux : lorsque cette aide indique « à côté du programme » (les dossiers htd et images, talen.lng et les réglages), la version Linux utilise le dossier ~/.local/share/advanced-html-designer de votre dossier personnel. Vos modèles et réglages y sont conservés lors d’une mise à jour.
