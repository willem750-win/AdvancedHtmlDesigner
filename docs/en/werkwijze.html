Getting started

A complete table design, from an empty page to HTML code.

1. Prepare the page and the table

  1. On the Settings (S) tab, choose the page size (A3, A4, A5 or Letter, portrait or landscape).
  2. Go to the Table (T) tab and add rows and columns with AR and AC, or delete them with DR and DC.
  3. Set the default row height and column width with the spin edits, or drag the lines between the row and column headers.
  4. Put the table in the right place: hold Ctrl and drag the table, or enter the position in mm at Move X and Move Y.

2. Fill and format cells

  1. Double-click a cell (or press Enter / F2) to type text.
  2. Finish with Ctrl+Enter or click somewhere else. Esc cancels.
  3. Select one or more cells and use the Cell (C) tab for bold, italic, alignment, colours and font size.
  4. Want to format a whole row or column at once? Click the row or column header.

3. Merge cells

  1. Drag the mouse over the cells that should be joined.
  2. Click MC (Merge cells) on the Table tab.
  3. Use UMC to undo the merge.

4. Images and hyperlinks

  1. Select a cell and click Add image on the Cell tab. The image is copied to the images folder.
  2. Choose the alignment (left, centre, right) and the size of the image.
  3. For a text hyperlink: edit the cell, select the piece of text and click TH+.

5. Add text blocks

  1. Click in the designer where the text block should go.
  2. On the Text block (B) tab, click TBA.
  3. Double-click the block to type the text. Move it by dragging or with Move X / Move Y.

6. Save and export

  1. Save your design with the Save table designer button as an .htd file.
  2. Expand the roll-out panel at the bottom to view, copy or save the HTML code.
  3. Use Open test browser to see the result in your normal web browser.
