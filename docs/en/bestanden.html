Files & export

Saving and opening your design, and using the HTML code.

Saving and opening a design (.htd)

ButtonWhat does it do?
Save table designerSaves the complete design (table, formatting, images, text blocks and page) as an .htd file. By default in the htd folder next to the program.
Open table designerOpens a previously saved .htd file.

At startup, the last working file htd\temp.htd is loaded automatically.

Viewing and exporting the HTML code

Click Click here for extra functions at the bottom to expand the roll-out panel. You then see two tabs:

TabContent
Html DocumentThe complete HTML page, ready to save as a file or put on a website.
Html TableOnly the code of the table, to paste into an existing page.

On both tabs you can:

  • Copy to clipboard – copy the code to paste it somewhere else.
  • Save HTML document – save the code as an .html file.

The Html Document tab also has Open test browser: it shows the result in your normal web browser. The roll-out panel then closes again.

Images: the HTML refers to the images folder. If you move the page somewhere else, take that folder along.

Language file

The translations are stored in talen.lng next to the program. Edit them with Language... on the Settings tab.
