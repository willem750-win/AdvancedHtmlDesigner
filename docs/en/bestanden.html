Files & export

Saving and opening your design, and using the HTML code.

Saving and opening a design (.htd)

ButtonWhat does it do?
Save table designerSaves the complete design (table, formatting, images, text blocks and page) as an .htd file. By default in the htd folder next to the program.
Open table designerOpens a previously saved .htd file, or an .html file you saved with Save HTML document (see Re-opening HTML).

At startup, the last working file htd\temp.htd is loaded automatically.

Viewing and exporting the HTML code

Click Click here for extra functions at the bottom to expand the roll-out panel. You then see two tabs:

TabContent
Html DocumentThe complete HTML page, ready to save as a file or put on a website.
Html TableOnly the code of the table, to paste into an existing page.

On both tabs you can:

  • Copy to clipboard – copy the code to paste it somewhere else.
  • Save HTML document – save the code as an .html file.

The Html Document tab also has Open test browser: it shows the result in your normal web browser. The roll-out panel then closes again.

With PDF (Save as PDF) on the Html Document tab you save the page as a PDF file, in the paper size of the page and with all colours, images and text blocks. See also lesson 8 of the learning path.

Re-opening HTML

An HTML document saved with Save HTML document also contains your complete design, including the images, invisibly. You can re-open such an .html file later with Open table designer and keep editing it, even if you no longer have the .htd file.

  • You do not see any of this in the browser: the design is stored in a block that browsers do not display.
  • If you open the file on another computer, the images are extracted to a folder next to the HTML file (e.g. page_images).
  • Ordinary HTML files (from a website or another program) cannot be opened; you get a message instead.
  • Large images make the HTML file larger, because the images are stored in the design.
Images: the images are built into the HTML code (data:image/...). Your web page is a single file: there is no separate image folder to take along.

Language file

The translations are stored in talen.lng next to the program. Edit them with Language... on the Settings tab.
