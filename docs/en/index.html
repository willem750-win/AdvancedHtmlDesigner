Welcome

Advanced Html Designer lets you design an HTML table on a page visually, with formatted cells, images, hyperlinks and freely placed text blocks. You save the result as a design (.htd) or as HTML code.

The window

  • Designer – the large work area with the page, the rulers (in mm) and the table.
  • Toolbox – the floating button bar on the left. At the top, choose T, C, B or S to select which tab is shown.
  • Buttons at the top – open and save a design, help, about and close.
  • Roll-out panel at the bottom – click Click here for extra functions to see the HTML code and a preview of the result.
Tip: hold the mouse still over a toolbox button for a moment: a short explanation (hint) appears in the selected language.

The toolbox often switches tabs by itself: click a cell and Cell appears. The small button at the top left of the table headers opens Table, and the small button in a selected text block opens Text block.
