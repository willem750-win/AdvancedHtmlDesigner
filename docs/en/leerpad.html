Learning path

Learn to work with Advanced Html Designer step by step: from a first simple table to a neat web page. Every lesson has an example you can open straight away, short steps to make it yourself and an exercise with a solution.

  1. Your first tableRows and columns, typing text, saving and viewing the result: a shopping list.
  2. Formatting cellsBold, alignment, text colour and cell colour: the shopping list becomes easy to read.
  3. Merging cellsA title across the full width and double lessons: a school timetable.
  4. Borders and rounded cornersBorder colour, width, style and rounded corners: the price list of an ice cream parlour.
  5. ImagesAn image in a cell, aligning it and choosing its size: a product sheet.
  6. HyperlinksMaking text and images clickable: a page with your favourite websites.
  7. Text blocksFree text around the table: an invitation with a title and a framed note.
  8. From design to websiteSaving as a web page, reading the HTML code and carrying on later: a fruit shop.
Tip: work through the lessons in order. Each lesson builds on what you learned in the previous one. In every lesson the Open this example button opens the finished example in the designer; then make it yourself in an empty table.
