Text block tab (B)

Text blocks are free text boxes you can put anywhere on the page, separate from the table – for example for a title, a note or a footer.

Placing and editing a text block

  1. Click in the designer where the block should go.
  2. Click TBA.
  3. Double-click the block (or press Enter / F2) to type the text.
  4. Drag the block to move it. Drag the bottom-right corner to resize it.
  5. The small button at the top left of a selected block opens this tab directly.
Note: most buttons on this tab only become active when a text block is selected.

Add, delete and position

ButtonNameWhat does it do?
Add text blockCreates a new text block where you last clicked in the designer.
Delete text blockDeletes the selected block. Delete works too.
XMove XHorizontal position of the block in mm, measured from the zero point of the rulers.
YMove YVertical position of the block in mm.

Move X and Move Y follow along when you drag the block with the mouse. So you can drag a block roughly into place and then set it to the exact millimetre.

Text formatting

ButtonNameWhat does it do?
BoldBold on or off.
ItalicItalic on or off.
UnderlineUnderline on or off.
Align leftText on the left of the block.
CentreText in the middle.
Align rightText on the right of the block.
■Text colourColour of the text.
⇅Font sizeSize of the text (8 to 20).

If you are editing the text and have selected a part of it, bold, italic and underline apply only to that part. Without a selection they apply to the whole block.

Hyperlinks

ButtonNameWhat does it do?
Create hyperlinkTurns the selected text into a hyperlink. First select the piece of text that should become a link.
Delete hyperlinkRemoves the hyperlink; the text stays.
